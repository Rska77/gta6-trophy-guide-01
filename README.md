# Leonida Platinum - GTA VI Trophy Guide & Tracker: all 55 trophies, 6-stage roadmap, missables flagged, every guide sourced

A single-page companion for planning the GTA VI platinum: browse all 55 trophies, follow a six-stage roadmap, spot missable trophies before they slip away, and open each trophy's guide with its sources. Progress is tracked in the browser, so the whole guide works offline and keeps your checkmarks between sessions.

## Run it

Serve the `app/` folder with any static file server — `node serve.ts` works — then open the URL it prints in a desktop browser. The guide is fully static and works offline; no install or build step is needed.
