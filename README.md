# Leonida Platinum - GTA VI Trophy Guide & Tracker: all 55 trophies, 6-stage roadmap, missables flagged, every guide sourced

A complete, spoiler-aware route to the Grand Theft Auto VI platinum on PlayStation 5. It covers all 55 trophies across a six-stage roadmap, flags missable awards and moments worth saving first, and gives every trophy a sourced guide. The tracker keeps earned trophies in your browser, shows progress by phase, and can export or import your checklist as plain JSON. Everything runs offline from the `app/` folder.

## Run it

Serve the `app/` folder with any static file server — `node serve.ts` works — and open the printed URL in a desktop browser. The guide works fully offline.

```sh
node serve.ts
# app/ is on http://localhost:8080
```
